# Connector

**Старый iPad как второй монитор для Linux — по кабелю, Wi-Fi или через интернет.**

[English version](README.md)

Аналог Duet Display и spacedesk для Linux (X11) и iPad, на которые уже не ставятся современные
приложения: приложение рассчитано на **iOS 12**, подходят iPad mini 2/3, iPad Air и новее.
Для системы iPad — обычный монитор: окна перетаскиваются на него, разворачиваются на нём,
расположение меняется в настройках экрана.

- **Малая задержка:** H.264 через NVENC (или x264), аппаратный декодер на iPad, неизменные кадры не передаются
- **Кабель, Wi-Fi или интернет:** USB через usbmuxd. По сети — TLS с ключом, полученным по кабелю.
  Компьютер в локальной сети находится сам, а подключённый кабель перехватывает соединение
- **Касание или тачпад:** клик касанием, перетаскивание, правая/средняя кнопка, прокрутка двумя пальцами;
  или курсор, как на тачпаде ноутбука
- **Клавиатура:** экранная (с Esc, Tab, Ctrl, Alt, стрелками…) или подключённая к iPad, с сочетаниями клавиш;
  текст на любом языке при любой раскладке компьютера
- **Второй монитор или повтор** экрана ноутбука, размер текста 100–200%, поворот по ориентации iPad
- **Бесплатный Apple ID:** приложение напомнит (на iPad и на компьютере), что 7-дневная подпись скоро истечёт

## Состояние

Работает каждый день на одной конфигурации: Linux Mint 22 (Cinnamon, X11), ноутбук с Intel + NVIDIA,
iPad mini 3 с iOS 12.5.8. На других системах, подходящих под требования, должно работать, но не проверялось.
Сообщения об ошибках и pull request'ы приветствуются.

## Требования

- **Linux с X11** (Wayland не поддерживается: захват и ввод сделаны через X11)
- **Свободный разъём HDMI или DisplayPort** на видеокарте Intel или AMD (драйвер ядра i915/xe/amdgpu/radeon/nouveau).
  В него ничего не вставляется: ядру говорят, что монитор подключён, и система получает виртуальный монитор.
  Проприетарный драйвер NVIDIA так не умеет, но на гибридных ноутбуках разъём обычно есть у Intel/AMD
- NVIDIA для NVENC — по желанию; без неё используется x264 (больше нагрузка на процессор)
- iPad с iOS 12 или новее и кабель
- Бесплатный Apple ID для подписи приложения (аккаунт разработчика не нужен)

## Установка

### 1. Хост (Linux)

```sh
sudo apt install build-essential libx11-dev libxext-dev libxfixes-dev libxrandr-dev libxtst-dev \
    libavcodec-dev libavutil-dev libswscale-dev libusbmuxd-dev libssl-dev libxkbcommon-dev usbmuxd
make -C host
sudo scripts/install.sh     # права на свободный разъём, порт 27183 в ufw
scripts/autostart on        # запуск вместе с сеансом (выключить: scripts/autostart off)
```

Свободный разъём определяется при первом запуске и сохраняется в `~/.config/connector/config`
(`CONNECTOR_OUTPUT` — имя в xrandr, `CONNECTOR_DRM` — имя в ядре, как в `/sys/class/drm/card*-ИМЯ`).
Если определился не тот, поправьте файл. Проверка: `scripts/connector-display on` — в настройках экрана
появится новый монитор; `scripts/connector-display off` — убрать.

### 2. Приложение для iPad

Собирается на Linux (clang + iOS SDK), подписывается и устанавливается через `plumesign`
из [Impactor](https://github.com/claration/Impactor).

```sh
sudo apt install clang lld
# iOS SDK, например iPhoneOS12.4.sdk из https://github.com/theos/sdks, — в .deps/
mkdir -p .deps && cp -r /путь/к/iPhoneOS12.4.sdk .deps/

plumesign account login -u ВАШ_APPLE_ID   # один раз; ввести код 2FA
scripts/ipad-install                      # iPad подключён кабелем и разблокирован
```

- На iPad один раз доверьте разработчику: Настройки → Основные → Управление устройством.
- Код 2FA: если его не показывает ни одно доверенное устройство, включите на iPad авиарежим и получите
  код в Настройки → [имя] → Пароль и безопасность → Получить код проверки.
- В Impactor 2.7.0 вход падает с `Plist error: Serde(... <html> ...)`; нужна версия с исправлением
  из claration/Impactor#288. `plumesign` должен быть в PATH, или задайте `PLUMESIGN=/путь/к/plumesign`.
- Каждому Apple ID нужен свой bundle id. По умолчанию `io.github.connector.<имя пользователя>`;
  чтобы сохранить уже установленный, запишите его в `~/.config/connector/bundle-id`.
- **Бесплатная подпись живёт 7 дней.** До истечения снова запустите `scripts/ipad-install`;
  iPad и компьютер напомнят об этом за день.

### 3. Привязка

Откройте Connector на iPad, подключённом кабелем. Появится монитор, а iPad получит ключ для Wi-Fi
(`~/.config/connector/key`). Дальше в той же сети Wi-Fi достаточно открыть приложение.

## Работа

Хост ждёт в фоне. Открыли Connector на iPad (с кабелем или в той же сети Wi-Fi) — появился монитор;
закрыли приложение или отключили — через 10 с монитор исчезает, окна возвращаются на остальные экраны.
Лог: `~/.cache/connector.log`. Вручную, без службы: `scripts/connector -v`.

### Жесты

| Жест | Режим «касание» | Режим «тачпад» |
|---|---|---|
| касание | левый клик в этой точке | левый клик там, где курсор |
| движение одним пальцем | перетаскивание левой кнопкой | двигает курсор |
| касание, снова касание и движение | — | перетаскивание левой кнопкой |
| удержание ~0,5 с | правый клик | правый клик |
| касание / удержание двумя пальцами | правый клик / средняя кнопка | так же |
| движение двумя пальцами | прокрутка | прокрутка |
| касание тремя пальцами | настройки | настройки |
| касание четырьмя пальцами | клавиатура | клавиатура |

### Клавиатура

Касание четырьмя пальцами (или Настройки → Клавиатура). Над экранной клавиатурой — Esc, Tab, Ctrl, Alt,
Win (они «залипают» до следующей клавиши), стрелки, Home/End, PgUp/PgDn и Del. Текст приходит как набран,
на любом языке, какая бы раскладка ни была включена на компьютере. Клавиатура, подключённая к iPad,
тоже работает, когда клавиатура открыта: стрелки, Esc и сочетания (Cmd работает как Ctrl).

### Настройки (касание тремя пальцами)

| Настройка | |
|---|---|
| Экран iPad | второй монитор или повтор экрана ноутбука |
| Размер текста и окон | 100% — родные 2048×1536 (резче всего, мельче всего), до 200% — 1024×768 |
| Чёткость | качество кодирования (NVENC cq 22 / 16 / 12) |
| Ориентация | авто / альбомная / книжная; в книжной монитор становится вертикальным |
| Указатель | касание в точку или тачпад |
| Индикатор | способ связи и частота кадров в углу |
| Wi-Fi и интернет | с каким компьютером связан, как подключён сейчас, адрес в интернете |

Текст чище при сглаживании шрифтов «оттенки серого» вместо «RGB»: H.264 хранит цвет с половинным
разрешением, и цветная окантовка букв размывается.

## Wi-Fi и интернет

**Одна сеть Wi-Fi:** настраивать ничего не нужно. Приложение находит компьютер широковещательным запросом
(UDP 27183) и подключается к TCP 27183. В гостевой сети с изоляцией клиентов работать не будет.

**Через интернет** компьютер должен быть доступен снаружи, например:

- проброс порта на роутере: TCP 27183 → компьютер, плюс DDNS-имя. Не сработает при «сером» IP (CGNAT).
- Tailscale Funnel (не проверено): `sudo tailscale funnel --bg --tcp 10000 tcp://localhost:27183`,
  адрес `имя-машины.ваш-tailnet.ts.net:10000`. Сам Tailscale на iOS 12 не ставится.

Адрес задаётся на компьютере (iPad получит его при следующем подключении кабелем):
`echo myhome.example.com:27183 > ~/.config/connector/address` — или вводится на iPad: Настройки → Адрес в интернете.
Порядок поиска на iPad: запрос в Wi-Fi → последний адрес в Wi-Fi → адрес в интернете.

Трафик шифруется TLS 1.2 с общим ключом (PSK-AES128-GCM-SHA256); без ключа подключиться нельзя.
Отвязать все iPad: удалить `~/.config/connector/key`, перезапустить службу и снова подключить кабелем.

Битрейт: по кабелю до 80 Мбит/с, по Wi-Fi до 30, через интернет до 10 (`--lan-bitrate`, `--internet-bitrate`).
Если сеть не успевает, хост пропускает кадры, а не копит очередь, — задержка не растёт. Только кабель: `--no-network`.

## Если не работает

- **Не появляется монитор:** `scripts/connector-display on` напишет, в чём дело; проверьте
  `~/.config/connector/config` и `xrandr`.
- **В логе «TLS handshake failed»:** iPad не привязан к этому компьютеру — подключите кабелем один раз.
- **iPad не находит компьютер по Wi-Fi:** проверьте файрвол (`sudo ufw status`, порт 27183 tcp и udp)
  и что оба в одной сети.
- **Приложение не открывается:** истекла подпись — запустите `scripts/ipad-install`.
